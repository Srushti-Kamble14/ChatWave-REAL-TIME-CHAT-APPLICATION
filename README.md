🔗 ChatTWavE
<br>
<br>
ChatWave is a real-time chat application built with React (using Vite), Tailwind CSS for styling, GSAP for animations, and WebSockets for real-time communication. The application allows users to log in or sign up, enter a chat room, and send and receive messages instantly.


<hr>
🔗 FEATURES
<br>
<br>
• Login and Signup functionality<br>
• Real-time messaging using WebSockets<br>
• Display of dynamic usernames <br>
• Responsive and mobile-friendly design <br>
• Dark theme using a black and dark blue color palette <br>
• Animated interface using GSAP <br>
• Welcome screen with conditional display <br>

🔗 Installation and Setup
<br>
<br>
1. Clone the repository:
   git clone https://github.com/Srushti-Kamble14/ChatWave-REAL-TIME-CHAT-APPLICATION.git <br>
   cd ChatWave-REAL-TIME-CHAT-APPLICATION <br>
<br>
2.Install all dependencies: npm install 

3.Start the development server: npm run dev

4.Open the application in your browser at:http://localhost:5173

<hr>
🔗 Required NPM Packages
<br>
<br>
Ensure the following packages are installed: <br>
